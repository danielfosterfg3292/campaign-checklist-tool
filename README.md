## What Campaign Checklist Does

Campaign Checklist gives campaign creators a dedicated review stage before their work is considered complete. Because it runs on the web, the tool can be used through a browser without installing a separate desktop application.

Its purpose is to make campaign review more consistent by collecting relevant checks in a clear, checklist-oriented workflow. This provides a structured way to revisit campaign details whenever another review pass is needed.
